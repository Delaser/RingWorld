# RingWorld for Minecraft 1.21.1

Build and explore a finite world wrapped into a complete ring. Travel around the
circumference without a world-border teleport, look up to see the far side, and
keep ordinary Minecraft gravity and gameplay. The Nether and End retain their
normal geometry.

Create a RingWorld using the world-creation controls, then use the Ring Atlas
for a complete overview and world settings. Distant terrain streams into the
Atlas as it is generated; real nearby chunks provide gameplay and collision.

Choose the file for your loader: Fabric or NeoForge. Minecraft 1.21.1 and Java 21
are required. Fabric also requires Fabric API. Install RingWorld on the server
and every connecting client, using matching versions.

Build, gameplay, rendering and save/reopen checks were performed on Windows x64
with Minecraft's vanilla renderer. Extended stress qualification was not completed.
Other operating systems, Sodium, shader packs and general modpack compatibility
are outside this release's acceptance evidence. Minecraft 1.20.1 support is a
separate project and is not included in these files.

RingWorld is open source under MPL-2.0. Source and licence information are
available at https://github.com/Delaser/RingWorld.
