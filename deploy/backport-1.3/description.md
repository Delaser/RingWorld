# RingWorld for Minecraft 1.21.1

RingWorld turns the Overworld into a finite cylindrical band. Walk around its
circumference and return to the same blocks; the distant Atlas shows the rest
of the ring beyond ordinary chunk distance. The Nether and End retain normal
geometry.

Choose your dimensions, terrain options, walls, sky and seed in the five-page
creation editor. Open the RingWorld Map during play to manage full-ring
generation and local display detail. Nearby chunks remain authoritative for
blocks, collisions and gameplay.

Use Java 21 and the matching Fabric or NeoForge file for Minecraft 1.21.1 on
the server and every client. Fabric requires Loader 0.16.14 or newer plus
Fabric API for 1.21.1. NeoForge requires 21.1.239 or newer. Cross-loader
multiplayer and broad modpack/shader-pack/Create compatibility are not claimed.
Back up worlds before upgrades; older Atlas data is regenerated from real
terrain, and large rings require more time, memory and disk space.
