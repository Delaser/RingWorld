# RingWorld 1.3 release preparation

Scope: six mod jars for Minecraft 26.1–26.1.2, 26.2 and 26.3 on Fabric and
NeoForge, published to CurseForge. Modrinth, optional launcher bundles,
saved-world upgrades and older full nightly sweeps remain outside the agreed
scope. The owner authorized continuation and publication on 29 September,
including continuing below the former usage limit.

Run fresh quick artifact/startup qualification for all three lines and the
26.3 nightly runtime checks. Test the staged NeoForge jars with newer loader
builds; accepted loader ranges are minimum-only while Minecraft remains bounded.
Inspect staged metadata, source links and hashes before upload, then verify
hosted downloads. Do not substitute the older development evidence for final
candidate checks.

The changelogs contain only changes since the published 1.2 source. Additional
26.3 rendering changes appear only in its changelog. Final qualification,
staging and upload results will be recorded here and in the publication record.
