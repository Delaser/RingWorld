## RingWorld 1.1 — Minecraft 26.1 through 26.1.2 ({{LOADER}})

This release extends the same RingWorld 1.0 implementation across the stable
Minecraft 26.1 patch line. One unchanged loader-specific build passed the
automated dedicated-server matrix on 26.1, 26.1.1, and 26.1.2.

- True periodic Overworld travel, interactions, entities, vehicles, combat,
  portals, structures, block entities, redstone, fluids, maps, and compasses.
- Curved nearby terrain plus the progressively generated full-ring Atlas.
- Small, Medium, and Large presets plus immutable custom ring dimensions.
- New worlds use seamless annular terrain noise; existing saved mapping
  identities remain preserved.

{{INSTALL_NOTE}}

The distant ring fills in progressively. A fogged, biome-coloured placeholder
appears first, then terrain colour and height detail replace it as the Atlas is
generated. Progress survives restarts and completion time depends on ring size,
seed, machine, server load, and other mods.
