FIRST ASSIGNMENT: S1 SOURCE AND PORT AUDIT

Create:

   docs/PORTING_26_1_AUDIT.md

This is a research and documentation task. Do not modify production code.

The audit must cover:

1. Minecraft 26.1.2, Java 25, Fabric Loader, Fabric API, Loom, mappings, and
   Gradle toolchain changes.

2. Every one of the project’s 35 mixins. For each mixin record:

   - RingWorld mixin class;
   - current Minecraft 1.21.11 target;
   - candidate Minecraft 26.1.2 target;
   - method descriptor or field changes;
   - injection strategy;
   - confidence level;
   - migration risk;
   - source evidence;
   - required validation test.

3. Fabric API imports and anticipated Mojang-name/API replacements.

4. Rendering changes, including shaders, uniforms, render pipeline APIs,
   chunk geometry, sky rendering, frustum behavior, and Blaze3D constraints.

5. Networking and custom payload API changes.

6. World and dimension storage changes, especially any code that manually
   constructs Overworld paths.

7. World generation, chunk ownership, entity, command, UI, client lifecycle,
   and automated-test API changes.

8. Removed or renamed APIs and every unresolved question.

Use official Mojang and Fabric sources. Do not mark a mixin target as resolved
without inspecting the Minecraft 26.1.2 source. You may create disposable
reference checkouts outside the RingWorld repository, but do not commit them.
