# Minecraft 26.3 test sweep — 2026-09-15

Owner request: run all tests and list errors, continuing below the usage pause
threshold and past individual failures. Tested source: `a5c33b6` (implementation
unchanged from `e880952`). No production code was modified during this sweep.
This is development evidence, not release qualification.

## Distinct findings

1. **Required projectile collision mixin targets an obsolete method descriptor.**
   `src/main/java/dev/ringworld/mixin/ProjectileUtilMixin.java:62` injects into
   `ProjectileUtil.getManyEntityHitResult(Level, Entity, Vec3, Vec3, AABB,
   Predicate, float, ClipContext.Block, boolean): Collection`. Minecraft 26.3
   cannot match that signature. The failing handler is
   `ringworld$periodicPiercingCollisions`. This blocks integrated world entry,
   client packet handling and server projectile handling. Map/compass, rigid
   objects, layout switching, lifecycle, seam/rim visual checks, all four
   projection environments, multiplayer and raid clients reproduce it.
   Port the required hook while preserving periodic projectile/piercing behavior;
   making the injection optional would hide the regression.
2. **Static source-selection assertion still assumes 26.3 uses the 26.2 adapter.**
   `scripts/test_minecraft_version_sources.py:47` expects `"26.2"` from
   `selected_source_abi("26.3")`; actual selection is correctly `"26.3"` after
   the new directory was added. Update the test's reviewed ABI expectations.
3. **Disposable multiplayer configuration omits the whitelist policy.**
   The initial 26.3 run wrote `white-list=true` and rejected both RingTester
   clients with “You are not white-listed on this server!” before gameplay.
   `prepareMultiplayerHarness` and `prepareRaidSeamTestWorld` do not explicitly
   configure this property. An ignored test-only init script set
   `white-list=false` on these disposable servers. The subsequent multiplayer
   and raid attempts reached the projectile failure above. No normal server
   configuration was changed. The repository fixture defaults still need an
   explicit admission policy.
